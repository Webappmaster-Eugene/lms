# Источник анализа собеседований

Чистые алгоритмы перенесены 2026-10-11 из собственного проекта владельца
`105.sovetnik/app`, commit `279d13a710f021729bf85eacaefb9719b4faa56d`:

- `src/interview/criteria.ts`, `scoring.ts`, `report.ts`, `prompts.ts`, `errors.ts`
- `src/transcribe/meetingTranscript.ts` (чистые функции), `meetingPrompt.ts`
- типы Interview* из `src/shared/types.ts`, шкала из `src/shared/constants.ts`
- очистка текста из `src/presentations/sanitize.ts` и Markdown helper.

Сохранены шкала уровней, JSON-отчёт, проверка цитат и детерминированный
подсчёт баллов. LMS использует изолированный временный каталог и строго
запрещает оценивать неполную расшифровку: неуспешный фрагмент останавливает
анализ. Куски по 10 минут; метки спикеров и контекст передаются последовательно.
Отдельная адаптация LMS — базовые критерии по направлению и рекомендации
для развития собственного навыка прохождения собеседования.

Видео скачивается по серверной проверенной ссылке Яндекс.Диска. Ключ OAuth
Диска и ключ OpenRouter никогда не передаются клиенту. До явного запуска
анализа запись не отправляется внешнему AI-провайдеру.

Граница 10 минут учитывает Opus padding: хвост короче 2 секунд включается
в предыдущий фрагмент, вместо пустого отдельного запроса STT. Проверено
реальным ffmpeg на 600.0065 и 605.0065 секунд в Linux.
