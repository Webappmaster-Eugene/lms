# Markdown в редакторе гайда

Поле «Текст гайда» в CMS поддерживает режимы «Markdown», «Рядом» и «Просмотр».
Выделите текст и нажмите кнопку панели: заголовок, список, жирный, курсив,
код, ссылка, таблица или врезка. «Как оформить Markdown» содержит памятку.

- `## Раздел` добавляет заголовок и пункт оглавления статьи.
- `- Пункт` создаёт список. Enter продолжает его, Enter на пустом пункте завершает.
  Работают нумерация, вложенные пункты и чек-листы; новый чекбокс всегда пустой.
- Списки с `•`, `◦` и `▪` при вставке преобразуются в Markdown. В существующем
  тексте это делает кнопка «Исправить списки •». Код и HTML в примерах не меняются.
- Пустая строка создаёт новый абзац. Два пробела в конце строки — перенос
  внутри абзаца. Одиночный перенос по правилам Markdown становится пробелом.
- Ctrl/Cmd+B, I, K вставляют жирный, курсив и ссылку. Ctrl/Cmd+Z отменяет
  изменения панели и преобразование списков в браузерах с `insertText`.

Предпросмотр обновляется до сохранения. Кнопка Save в CMS сохраняет новую
версию; опубликованный гайд обновляется по прежнему адресу.

`GuideMarkdownContent.tsx` и `guide-prose.css` общие для превью и страницы:
разбор GFM, заголовки, списки, таблицы, картинки, врезки и блоки кода с копированием.
Шрифт Inter общий. В CMS палитра берётся из темы Payload, на сайте — из темы LMS.
Подсветка Shiki в CMS загружается в браузере, на странице — на сервере.
Сырой HTML не исполняется.
