# Записи и анализ собеседований

`/interviews`: расширяемые направления из CMS, общие записи ментора/других людей
и приватная папка «Мои собесы». Личные видео и результаты доступны только владельцу,
включая стандартный Payload API. Администратор управляет общей библиотекой.

## Настройка

В Dokploy Environment приложения LMS:

- `YANDEX_DISK_TOKEN`: OAuth Диска с чтением и записью.
- `YANDEX_INTERVIEWS_ROOT`: приватная папка, по умолчанию `disk:/LMS interviews`.
- `INTERVIEW_ANALYSIS_API_URL`: HTTPS origin существующего Советника.
- `INTERVIEW_ANALYSIS_API_TOKEN`: отдельный серверный ключ интеграции.

В Dokploy Environment бота:

- `LMS_INTERVIEW_API_TOKEN`: тот же серверный ключ.
- `LMS_INTERVIEW_SOURCE_ORIGIN`: публичный HTTPS origin LMS.

Обработка выполняется существующим режимом оценки собеседований Советника:
расшифровка с разделением спикеров, критерии вакансии, оценка ответов и грейда.
LMS передаёт контекст и видео, сохраняет полученный структурированный отчёт в своей
БД. Его просмотр и скачивание не требуют работающего внешнего сервиса.

## Запись и контекст

Загрузка потоковая на приватный Яндекс Диск: MP4, WebM, MOV, MKV до5ГБ,
20 записей/10ГБ на ученика. Просмотр поддерживает GET/HEAD/Range/private no-store.
По завершении независимо проверяются фактические размер и MIME. Неудачные внешние
удаления сохраняют строку записи, чтобы можно было повторить операцию.

Анализ запускает только владелец готовой личной записи по явному согласию.
Выбираются ожидаемый грейд и формат: технический разговор, live coding,
системное проектирование, HR или смешанное собеседование. Можно добавить вакансию
и имя кандидата. Направление берётся из CMS и фиксируется вместе с контекстом.
Без вакансии результат оценивает подготовку к грейду, с явным ограничением:
соответствие конкретной вакансии не проверено.

Отчёт содержит критерии с оценками и цитатами, подтверждённость цитат, покрытие
тем, грейд с уверенностью, коммуникацию, сильные стороны, риски, точки роста,
уточняющие вопросы и ограничения. Отсутствие темы не считается плохим ответом.
Для live coding без визуального анализа нельзя подтвердить правильность кода
по одному аудио; это ограничение показывается в отчёте.

## Надёжность и приватность

`POST /api/integrations/lms/interviews` создаёт задание в боте с уникальным UUID
попытки, owner ID LMS и детерминированным защищённым HTTPS источником. Bearer ключ
доступен только серверу. Повтор того же тела возвращает существующее задание;
смена владельца/входных данных с тем же UUID отклоняется. GET и DELETE проверяют
владельца. Telegram identity и доставка в чат в этом подключении не используются.

Источник видео подписан HMAC на одну запись/владельца/попытку на24ч. При скачивании
LMS получает свежую CDN-ссылку Диска; подписанные ссылки не выдаются браузеру.
Источник отзывается после завершения/ошибки/удаления. URL разрешён только с
настроенного LMS origin; перенаправления и посторонние URL отклоняются.

Короткие шаги LMS scheduler используют durable PostgreSQL state и lease5мин.
Потерянный ответ POST безопасно повторяется с тем же UUID/источником/контекстом.
Бот сохраняет checkpoints расшифровки/критериев и не повторяет неопределённые
платные этапы после аварии. Лимит LMS —3 запуска/сутки UTC и3 попытки/запись;
удаление видео не сбрасывает квоту. Старые поля и применённые миграции сохраняются
для совместимости работающей схемы.
