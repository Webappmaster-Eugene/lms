# Порядок прохождения роадмапов

Карта, мобильный список и «Следующий шаг» используют одну последовательность.
Порядок задаётся `roadmap-nodes.order`; при одинаковом или незаполненном порядке
его уточняют координаты Y, затем X и стабильный `nodeId`. Темы располагаются
слева направо, по четыре в строке; следующая строка снова начинается слева.
Переходы соединяют только соседние шаги, без ложных параллельных треков.

React начинается HTML → CSS → JS → JS + DOM, Backend Node.js — JS → TS.
DevOps переносит ошибочно размещённые ранние темы Observability и Deploy Fullstack
после Kubernetes. Правила не добавляют запреты доступа к уже назначенным курсам.
Номера шагов и рекомендация следующего непройденного курса согласованы между
картой и списком. Материалы без уроков и недоступные курсы пропускаются при
рекомендации; структура карты сохраняется.

## Нормализация существующих данных

`src/normalize-roadmaps.ts` работает через Local API Payload от имени существующего
администратора с `overrideAccess: false`. По умолчанию выполняется только preview:

```sh
pnpm exec tsx src/normalize-roadmaps.ts
pnpm exec tsx src/normalize-roadmaps.ts --slug=frontend-react
```

Нужны `DATABASE_URL`, `PAYLOAD_SECRET` и `ROADMAP_NORMALIZE_ADMIN_EMAIL` в окружении.
Скрипт отключает application `onInit`, автоматические сиды, schema push и
production migrations. Пароли и токены в отчёт не выводятся.

После проверки плана запись включается явно:

```sh
pnpm exec tsx src/normalize-roadmaps.ts --slug=frontend-react --apply
```

Каждая карта записывается и перечитывается в одной транзакции. ID тем,
`nodeId`, курсов, slug, привязки курсов, содержимое и учебный прогресс сохраняются.
Подходящие связи сохраняются; остальные переиспользуются для последовательных
переходов, удаляются только лишние связи. Новые связи получают префикс ID карты.
Повторное применение не пишет уже нормализованные документы.

Продовые данные в рамках разработки не менялись. Применение на проде — отдельная
операция после просмотра плана для фактического каталога. Не используйте
`seed-roadmaps.ts` вместо нормализатора: seed пересоздаёт темы.

Проверки: `tests/unit/roadmapSequence.test.ts`, `roadmapLayout.test.ts`,
`roadmapNextStep.test.ts`, `tests/integration/cms/roadmapSequences.test.ts`.

Проверка readonly-снимка каталога от 2026-10-10:
`tests/unit/roadmapCatalogSequence.test.ts` моделирует все 9 опубликованных карт
(86 узлов) с разной высотой карточек. Снимок подтверждает, что поля `order`
уже задают правильный учебный порядок; ошибочное впечатление параллельного
обучения создавали старые связи и раскладка. Проверяются все последовательные
переходы, чтение слева направо/сверху вниз, сохранность ID и отсутствие наездов
карточек и стрелок. Учебный контент и пользовательские данные в снимок не входят.
