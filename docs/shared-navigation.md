# Общие ссылки на обучение

Каталог курсов хранит в URL поиск `q`, роадмап `roadmap`, статус `status`,
фильтр назначений `assigned`, сортировку `sort` и страницу `page`.
На роадмапе сохраняются режим `view`, выбранная тема `topic` и поиск `q`.
Переходы назад, повторное открытие и отправка на другое устройство восстанавливают
явные параметры ссылки; настройки устройства применяются при их отсутствии.

Каталог курсов и роадмап фильтруют данные в браузере, а их серверные страницы
параметры не читают. Поэтому адрес меняется через `window.history.pushState` и
`replaceState`: Next синхронизирует их с `useSearchParams` без запроса к серверу.
Раньше `router.push` перерисовывал всю страницу на сервере, и на телефоне нажатие
фильтра секунду-две ничего не меняло. Каталог задач тренажёра фильтрует сервер:
выбор сразу показывается через `useOptimistic`, вместо счётчика — «Обновляем список…».
Поля поиска (`useUrlSearchText`) не принимают из адреса собственный запоздавший
запрос, иначе на медленной сети пропадали набранные символы.

Кнопка «Поделиться» вызывает системное меню телефона или копирование ссылки.
Если браузер не поддерживает эти возможности, доступно ручное копирование.
Ссылка на задачу содержит выбранный язык `lang`, без кода решения.
У плеера «Поделиться этим моментом» добавляет `video`, секунду `t` и скорость `rate`.
Явный фрагмент имеет приоритет над личным продолжением; остальные ролики урока
восстанавливают собственные позиции. При открытии фрагмента личная позиция
сама по себе не перезаписывается.

Вход сохраняет полный путь с параметрами. Получатель проходит обычную проверку
своих назначений; наличие общей ссылки не открывает закрытый курс или урок.
В общую ссылку попадают только разрешённые параметры навигации. Пароли,
токены, адреса исходных видео и черновики решений исключаются.
