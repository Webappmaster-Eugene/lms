# Библиотека собеседований

`/interviews` открывается из меню «Собеседования». Направления поступают из CMS,
поэтому React.js и Node.js backend можно дополнить другими языками. В каждом
направлении есть «Собесы ментора», «Чужие собесы» и «Мои собесы». Фильтры, поиск и
пагинация выполняются сервером; личные записи не приходят в браузер другого ученика.

## Загрузка и просмотр

«Добавить мой собес» открывает нативный dialog. Ученик выбирает направление,
название и файл MP4/WebM/MOV/MKV до 5 ГБ. Файл отправляется через авторизованный
API того же домена. После загрузки сервер проверяет появление записи на Яндекс
Диске. Прогресс означает отправку файла; запись готова после подтверждения диска.
Встроенный видеоплеер поддерживает мобильное воспроизведение `playsInline`.
При отправке большого файла интерфейс рекомендует стабильный Wi-Fi и предлагает
держать приложение открытым до окончания загрузки.

## Личный разбор

Анализ доступен владельцу готовой личной записи. До запуска ученик выбирает
целевой грейд и формат: технические вопросы, лайвкодинг, проектирование систем,
HR или смешанное собеседование. Можно добавить текст вакансии и имя кандидата
для различения спикеров. Если вакансии нет, оценка выполняется по направлению
и грейду; это ограничение явно показано в отчёте.

Перед отправкой нужно отдельное согласие на обработку записи и требований
сервисом разбора собеседований Советника. LMS получает и сохраняет его результат:
итог по критериям, оценку уровня, сильные стороны, зоны роста, коммуникацию,
риски и вопросы для подготовки. При ошибке введённые требования сохраняются
в открытом диалоге, чтобы ученик мог повторить запрос.

Отчёт показывает долю требований, которую удалось оценить. Необсуждавшиеся
критерии не считаются ошибками; при нулевом покрытии числовой итог не показывается.
Цитаты, подтверждённые расшифровкой, отличаются от непроверенных. Отчёт помогает
подготовиться к следующему собеседованию; решение о найме принимает человек.

Полный результат доступен в LMS владельцу записи. «Скачать отчёт» использует
защищённый `/api/interviews/:id/report` того же домена. Произвольный текст сервиса
выводится через React без исполнения HTML. Критерии и цитаты расположены
последовательно, без широкой таблицы на мобильных экранах; поля диалога на
телефоне идут одной колонкой и прокручиваются внутри нативного окна.

## Проверки

`tests/components/interviews.test.tsx` проверяет серверные фильтры, приватность
отображения, согласие, передачу контекста анализа, повтор после ошибки, отмену
polling, сохранённый отчёт, покрытие и непроверенные цитаты, безопасность HTML,
загрузку и запрет передачи файла на посторонний URL.

Геометрию мобильного окна и фокус проверять в настоящем браузере: jsdom не
воспроизводит нативную проверку `required` для file input. Компонентные тесты с
подменённым ответом сервиса не доказывают живую обработку внешним сервисом.
