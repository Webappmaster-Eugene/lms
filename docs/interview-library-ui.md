# Библиотека собеседований

`/interviews` открывается из меню «Собеседования». Направления поступают из CMS,
поэтому React.js и Node.js backend можно дополнить другими языками без изменения
компонентов. В каждом направлении есть «Собесы ментора», «Чужие собесы» и «Мои
собесы». Поиск и пагинация выполняются сервером; личные записи не приходят в
браузер другого ученика.

## Загрузка и просмотр

Кнопка «Добавить мой собес» открывает нативный модальный dialog. Ученик выбирает
направление, название и файл MP4/WebM/MOV/MKV до 2 ГБ. Файл отправляется XHR через
авторизованный API того же домена, затем сервер проверяет появление записи на
Яндекс Диске. Прогресс означает отправку на сервер; окончание загрузки
подтверждается отдельной проверкой. При отмене незавершённая запись удаляется.

Страница записи использует нативный плеер с `playsInline`, `preload="metadata"`
и приватным `/api/interviews/:id/stream`. Яндекс OAuth и приватные пути диска
не передаются клиентским компонентам. Видеозаписи и отчёты не сохраняются в
localStorage. Не все устройства воспроизводят MKV и отдельные кодеки MOV;
интерфейс рекомендует MP4 для просмотра на телефоне.

## Checkfrod

Кнопка анализа существует только у владельца готовой личной записи. Перед
запуском интерфейс объясняет передачу **видео** внешнему сервису Checkfrod.
Пользователь ставит обязательный флажок согласия, подтверждает, что участники
предупреждены об обработке и он вправе передать запись, затем нажимает
«Передать видео в Checkfrod». Запрос содержит `consent: true` и `roiSpec`.

Область лица кандидата выбирается автоматически (`auto`), по всему кадру
(`none`) или вручную координатами `x,y,ширина,высота` в пикселях. Координаты
должны быть от 0 до 32768, размеры — от 16 до 32768. Имя кандидата, текст
вакансии, расшифровка речи и HR-критерии для этой проверки не собираются.

Фоновый разбор опрашивается раз в пять секунд только в статусах queued/processing
и при видимой странице. Смена страницы или скрытие приложения прерывает запрос.
Готовая проверка не предлагает повторный запуск; неудачную можно повторить.
Если Checkfrod не подключён, кнопка отключена с объяснением.

LMS показывает фактическую сводку сервиса: длительность, число сигналов и
моментов для просмотра, время анализа по радужке/голове, отсутствие лица и
застывшие непроверенные фрагменты. Справочные эпизоды не считаются сигналами.
Для static-видео интерфейс не выдаёт минуты присутствия лица за проверку
взгляда и губ; для head_only, low и no_face объясняет ограничения качества.

**LMS не создаёт собственную оценку ответов, грейд или вердикт о списывании.**
Сигналы требуют самостоятельного просмотра записи. Точный отчёт с эпизодами,
моментами и кадрами открывается в Checkfrod: ссылка в интерфейсе ведёт на
`/api/interviews/:id/report`, сервер проверяет владельца и выдаёт новую
временную подписанную ссылку. Переход использует `noopener noreferrer` и
`referrerPolicy="no-referrer"`; подписанную ссылку нельзя передавать другим
людям, поскольку она открывает кадры записи.

## Проверки

`tests/components/interviews.test.tsx` проверяет приватность отображения,
явное согласие на Checkfrod, тело запроса и координаты области, отмену polling,
сообщения ошибок и отсутствие конфигурации, фактическую сводку и ограничения
static/head_only/frozen, защищённую ссылку на исходный отчёт, серверные фильтры,
ограничения файла и запрет отправки файла на посторонний URL.

Нативное окно, клавиатурный фокус, геометрию мобильного интерфейса и загрузку
файла проверять в настоящем браузере: jsdom не воспроизводит браузерную
проверку required у file input. Тесты с подменённым ответом Checkfrod не
доказывают живую обработку внешним сервисом.
