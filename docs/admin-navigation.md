# Навигация администратора

После входа под аккаунтом с ролью «Администратор» вверху бокового меню
платформы появляется раздел «Управление». На телефоне это же меню открывается
кнопкой «Ещё» в нижней панели.

## Курсы, разделы и уроки внутри LMS

Основной путь: **Управление → Учебный контент → нужный роадмап → курс →
программа курса**. Открытая карта также предлагает **Курсы и уроки** и
**Добавить курс**. В теме карты/списка этапов доступны **Добавить курс в тему**
и **Управлять курсами темы** — привязка выбирается автоматически.

Создание: **Добавить курс → название/описание → Создать черновик → Добавить
раздел → Добавить урок в раздел → описание/материалы → Создать черновик**.
Курс можно собрать без разделов; тогда уроки находятся непосредственно в курсе.

Материалы урока: текст с форматированием, видео, изображения, ссылки, Miro и
файлы. Изображения/файлы выбираются или загружаются в том же редакторе. Кнопки
со стрелками меняют порядок, удаление материала требует подтверждения.

Публикация выполняется явно: сначала **Настройки и публикация → Опубликовать
курс**, затем публикация раздела в программе и **Опубликовать урок** в редакторе.
Черновики видит только администратор. Ошибка при сохранении сохраняет введённый
текст; устаревшая вкладка не перезаписывает свежие изменения. Повтор создания
после потерянного ответа не создаёт второй документ.

С просмотра курса: **Редактировать программу**. С просмотра урока:
**Редактировать урок**. Кнопки назад и путь над заголовком возвращают к программе
и роадмапу. Несохранённые изменения защищены подтверждением выхода.

Описание курса выводится на его странице, описание урока — под заголовком и в
программе. Редкие сложные элементы существующего форматированного текста
сохраняются без преобразования; если редактор не поддерживает элемент, он
сообщает об этом и разрешает изменить остальные поля.

CMS открывается отдельно: **Управление → CMS и настройки**. Прямые пункты
коллекций находятся в **Настройки контента в CMS** и других расширенных группах.

## Редактирование карты

**Управление → Редактор роадмапов → нужная карта → правки → Сохранить →
Открыть на платформе.** Просмотр открывается в новой вкладке и показывает
сохранённую карту. Кнопка «Все роадмапы» возвращает к выбору другой карты.

Если карта уже открыта на платформе: **Роадмапы → нужная карта →
Редактировать карту**. Администратор видит эту кнопку рядом с названием.

Название, описание, обложка и публикация меняются отдельно: **редактор →
Настройки роадмапа → правки → Сохранить → Открыть визуальный редактор**.
На странице просмотра есть такая же кнопка «Настройки роадмапа».

## Остальные задачи

| Задача | Путь в меню «Управление» |
|---|---|
| Создать ученика, поменять роль или пароль | Ученики и администраторы → пользователь |
| Ответить на вопрос | Вопросы учеников → обсуждение |
| Изменить программу курса | Учебный контент → курс → программа |
| Загрузить файлы | Редактор курса/урока → Выбрать или загрузить |
| Импортировать курс | Настройки контента в CMS → Импорт из Яндекс.Диска |
| Проверить предыдущие импорты | Настройки контента в CMS → История импорта |
| Изменить задания | Управление тренажёром → Темы / Задачи тренажёра |
| Проверить прохождение и награды | Прогресс и награды → нужный раздел |
| Изменить FAQ, уведомления и контакты | Общение и настройки → нужный раздел |

Группы раскрываются нажатием на название. Группа текущего раздела раскрыта
автоматически. Для управления всеми коллекциями можно открыть «CMS и
настройки»: её меню содержит коллекции и настройки, а блок «Управление» —
редактор, вопросы учеников, импорт и «Открыть платформу» для возврата к обучению.
В админке и редакторе боковое меню открывается кнопкой в левом верхнем углу.

Ученики видят меню обучения. Административные страницы и записи защищены
проверками прав независимо от видимости пунктов меню.
