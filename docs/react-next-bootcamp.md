# React + Next.js: frontend сервиса проката

Полный комплект по образцу Node.js-буткемпа: подготовка и 20 учебных этапов,
до 10 участников. Новая цена по запросу владельца от 18.11.2026 — 20 000 рублей.
Срок обучения - 12 недель, включая подготовку в первой неделе и защиту в последней.
Все 20 этапов и 84 урока сохранены. Нагрузка - 25-35 часов в неделю.
Календарь определён в program.json материалов и скопирован в данные лендинга;
новый поток React автоматически получает 20 сроков сдач в пределах 12 недель.
Номера week-NN и идентификаторы уроков остаются номерами этапов.
Дата старта не назначена. Два интерфейса подключаются к настоящему backend
Node.js-буткемпа: React для сотрудников, Next.js для клиентов.

Последовательный автоматизированный прогон 00–20 завершён в отдельном
[приватном проекте тестового ученика](https://github.com/Webappmaster-Eugene/frontend-bootcamp-student-rehearsal).
Выпуск `v0.20.0`, SHA `ab71d893461577f54cec58e567ac2de0174c9559`.
Журнал `JOURNEY.md` и `docs/defense-rehearsal.md` содержат проверки каждого этапа.
Это работа ИИ по методичкам, самостоятельность человека и устная защита не оценены.
Реальных платежей за обучение и тестового прогресса в production не создавали.

## Исходники и проверка

Комплект находится в рабочем каталоге `bootcamp/frontend/` рядом с репозиторием
LMS. Это три отдельных Git-репозитория: `content`, `starter`, `reference`.
Их приватные GitHub-репозитории в аккаунте `Webappmaster-Eugene`:
`frontend-bootcamp-content`, `frontend-bootcamp-starter`, `frontend-bootcamp-reference`.
Эталон, ответы и закрытые проверки не переносятся в публичный репозиторий LMS.
В `content/program.json` находится программа всех недель.

Материалы собираются из Markdown в PDF, HTML и пакет `bootcamp-package/1`.
Пакет содержит четыре урока каждой недели: методичку, практикум, самопроверку
и ответы. Команды и параметры импорта описаны в README репозитория материалов.

После сборки пакета `mentorcareer` и `pnpm build` полную проверку импорта
можно повторить одной командой из рабочего дерева LMS:

```sh
pnpm bootcamp:react-next:verify
```

Она поднимает production-сборку на порту рабочего дерева, создаёт отдельную
локальную БД с его префиксом и проверяет настоящий REST-импорт: 21 раздел,
84 урока, черновик по умолчанию, повтор с сохранением ID, явную публикацию,
настройку программы и доступ только по назначению. База удаляется, процесс
приложения останавливается; общий тестовый PostgreSQL остаётся другим сессиям.
Для другого расположения комплекта задайте `FRONTEND_CONTENT_DIR`.

До выпуска нужно проверить полный сценарий на настоящем API: регистрация,
вступление в организацию, бронь, оплата, выдача и возврат. Даты аренды имеют
семантику `[from, to)`, деньги берутся из серверного ответа. Сессия использует
`__Host-sid`, изменяющие запросы передают `x-csrf-token`. Next.js не заменяет
backend и не читает его БД напрямую.

## Подключение к LMS

Используются существующие коллекции и платёжный путь. Новая схема и миграция
для добавления программы не нужны. Настройки:

| Поле | Значение |
|---|---|
| Ключ программы | `react-next` |
| Курс | `react-next-bootcamp-manuals` |
| Лендинг | `/bootcamp/react-next/` |
| Цена | 4 500 000 копеек |
| Входное задание | `rental-frontend-js` |
| Starter в GitLab | `react-next/course` |
| Группа потока | `react-next-bootcamp` |
| Проект проверки | `react-next-staff/grading` |

Сначала импортируйте пакет методичек в выбранную локальную LMS с явным
роадмапом. Курс должен иметь `isBootcamp=true` и `assignedOnly=true`.
По умолчанию импорт создаёт черновик. Публикация курса и открытие набора
являются разными действиями.

Затем из репозитория LMS выполните проверку настройки. Учётные данные
`LMS_URL`, `LMS_ADMIN_EMAIL`, `LMS_ADMIN_PASSWORD` передаются окружением.

```sh
pnpm bootcamp:react-next:setup
```

Без `--apply` программа не создаётся. Проверка входит через авторизованный
REST API и подтверждает роль администратора, флаги курса и существующие
условия программы. Для создания отсутствующей записи:

```sh
pnpm bootcamp:react-next:setup --apply
```

Новая программа получает `isActive=false`. Результат перечитывается. Повтор
не создаёт дубль, не закрывает действующий набор и не перезаписывает цену,
оферту или репозитории существующей программы при расхождениях.

Входное задание содержит три функции JavaScript про каталог, строку поиска
и обновление массива. Знание React до поступления не требуется. Готовность
по HTML/CSS, Git и асинхронным запросам проверяется в начале первой недели.

Курс не открывается назначением всей карты или режимом «все курсы».
Зачисление после оплаты открывает только курс новой программы. Прохождение
frontend-буткемпа само по себе не открывает материалы Node.js.

## Перед открытием предзаписи

Проверить starter и закрытые проверки в рабочих проектах GitLab, полный
пакет материалов, связи программы, условия оферты и страницы лендинга.
Не переносить даты и расписание Node.js: для frontend они ещё не назначены.
Два групповых занятия занимают 2 часа и 1,5 часа в неделю, ревью приходит
не позднее пяти дней. Работа ученика занимает 25-35 часов в неделю.

Изменения production API и публикация требуют отдельного подтверждения
конкретных операций после локальной приёмки. Эта инструкция не является
разрешением на запись в production.

## Локальная приёмка 17.11.2026

Подготовлены 21 методичка, ответы, руководства наставника, 93 термина и
42 проверенных листинга. Отдельные PDF занимают 253 страницы, общий сборник
методичек - 200, закрытый сборник руководств - 67. Ученические пакеты не
содержат руководства наставника, закрытые проверки и окружение.

Настоящий браузер проверил полный путь двух интерфейсов через Node.js API:
регистрация, бронь, учебная оплата с webhook, фотография, выдача и возврат.
Все 20 приёмочных наборов прошли 60 проверок поведения и 40 независимых
подтверждений backend. Пустой starter не прошёл приёмку; намеренные ошибки
суммы, доступных имён и canonical обнаружены. Реальный срез недели 03
проходит свой набор и отклоняется набором 04. Срез Next.js 12 проверяет
доступность, но ещё не предлагает бронирование.

Проверка `bootcamp:react-next:verify` прошла на production-сборке локальной
LMS: 21 раздел, 84 урока, повтор без смены ID, явная публикация, закрытый
набор и доступ только по назначению. Полный набор LMS: 5738 тестов прошли,
3 пропущены штатно; typecheck и сборка прошли. У lint осталось прежнее
предупреждение Sidebar. В первом полном прогоне существующий тест AccessTree
дал нестабильное падение; отдельно и при повторном полном запуске он прошёл.

Готовый backend-runtime проверен на Linux/arm64 отдельно от приватного
Node.js-репозитория. Вариант Linux/amd64 можно собрать штатной командой
экспорта, но его запуск в этой приёмке не проверялся. Полная аналитическая
цепочка до ClickHouse проверена отдельным локальным профилем.

Linux VM, рабочие проекты GitLab и production не запускались и не менялись.
Независимое финальное ревью нового CI-адаптера остановлено автоматическим
фильтром сервиса и не считается пройденным; ограничения записаны также в
закрытой документации адаптера. Его локальные тесты и браузерная приёмка
приложений не заменяют проверку на подготовленном образе VM.
