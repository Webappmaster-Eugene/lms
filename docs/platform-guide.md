# Инструкция по платформе

С 2026-10-08 `landing/` — сайт-инструкция на https://info.mentorcareer.ru.
Видимые внешние ссылки ведут на https://learn.mentorcareer.ru и
https://nadtocheev.ru (сайт автора в шапке и подвале, на телефоне также
рядом с первым экраном).
Биография, реклама менторства и портреты удалены также из
JSON-LD, llms.txt и картинки Open Graph.

## Содержание

- `landing/src/data/guide.ts`: десять разделов, инструкции и координаты меток.
- `landing/src/data/faq.ts`: общий источник видимого FAQ и JSON-LD.
- `landing/src/components/GuideScreen.astro`: скриншот и доступные кнопки шагов.
- `landing/src/scripts/guide.ts`: выбор и показ шагов, увеличение скриншотов,
  оглавление с поиском и закреплённой мобильной навигацией, локальный
  чек-лист. Чек-лист не меняет учебный прогресс LMS.
- `landing/public/guide/`: 13 WebP-скриншотов настоящего интерфейса.
- `landing/src/data/screens.json`: размеры снимков для стабильной раскладки.

Снимки сделаны через Playwright в Linux-контейнере v1.63.0-noble,
против локального `scripts/e2e-server.mjs` на одноразовой базе
`lms_e2e_3100`. Это демонстрационный пользователь из
`tests/e2e/fixtures/data.ts`, реальные ученики не использованы.
Основной viewport 1440×1000, мобильный 390×844. На отдельных снимках
нижняя часть обрезана до начала подвала; личные упоминания из подвала
не входят в публикуемые снимки. В примере дашборда завершён первый урок,
в примере заметок сохранён конспект и добавлена закладка.

После изменения интерфейса снимки нужно переснять, проверить размер в
screens.json и координаты меток. Инструкция отражает реальные условия:
аккаунт выдаёт администратор; просмотр видео не завершает урок;
в тренажёре зачёт даёт успешная отправка на сервер.

## Домены

Оба домена подключены к одному `lms-mentor-landing:80` в Dokploy:
`info.mentorcareer.ru` отдаёт инструкцию, `promo.mentorcareer.ru` отвечает
301 на новый домен с исходными путём и query string. Редирект реализован
в `landing/nginx.conf`, поэтому старый домен нельзя удалять из Dokploy.
LMS остаётся на `learn.mentorcareer.ru`.

DNS info должен указывать на сервер Dokploy. Для HTTPS используется
Let's Encrypt. API ключи не сохраняются в репозитории.
[Управление доменами Compose в Dokploy](https://docs.dokploy.com/docs/core/docker-compose/domains).

## Проверки

`pnpm smoke`, `npm run build --prefix landing`, обе Docker-сборки.
Контент и сценарии инструкции: `tests/e2e/content/landing-seo.spec.ts`,
`landing-guide.spec.ts`, блоки лендинга в `a11y.spec.ts` и `links.spec.ts`.
Мобильный вариант проверен при 375 px; инструкция читается без JavaScript.
Предварительно убедиться, что nginx сохраняет пути при редиректе и
возвращает настоящий 404 для отсутствующих страниц нового домена.
