# Письма MentorCareer

Пять событий: приглашение в аккаунт, восстановление пароля, завершение курса,
завершение роадмапа и получение достижения. Письма, которые администратор
рассылает ученикам вручную, описаны в [email-broadcasts.md](email-broadcasts.md). Шаблоны и текстовые альтернативы
находятся в `src/payload/emails/templates.ts`; отправка событий —
`src/payload/hooks/sendNotification.ts`, восстановление — в auth-конфигурации Users.

Оформление использует графитовую шапку, белый фон и золотой акцент результата,
системные шрифты и табличную вёрстку с inline-стилями. Основное содержание
доступно без изображений и отдельного CSS-блока. У каждого письма есть скрытый
текст предпросмотра во входящих, один основной заголовок и понятное действие.
Курсы и роадмапы получают ссылку на свою страницу по slug. Если slug не передан,
ссылка ведёт в соответствующий каталог. Названия, имена, описания и адреса
экранируются перед вставкой в HTML; slug и reset-token кодируются в URL.

Приглашение содержит логин, первые шаги, срок ссылки7дней и переходы для входа
и запроса новой ссылки. Восстановление объясняет срок1час, одноразовость и
действия при незапрошенном сбросе. Учебные письма показывают фактическую награду
и предлагают закрепить материал, открыть профиль, сертификаты или каталог.
Нулевая/отрицательная/нечисловая награда не превращается в обещание начисления.
Тексты не обещают доступ ко всем материалам или наличие конкретного сертификата.

## Текстовая версия

Обычные хуки передают и `html`, и `text`. Payload3.89 при forgotPassword
передаёт только HTML. Обработчик Nodemailer `compile` в
`src/payload/email/textAlternative.ts` добавляет недостающий текст через
`html-to-text`, сохраняя ссылки и русские символы. Он исключает скрытый
preheader, не меняет явно переданную текстовую версию и не читает URL,
файлы или потоки ради преобразования HTML. Токены не сохраняются в кэше.
API расширения описан в [документации Nodemailer](https://nodemailer.com/plugins/create).

## Предпросмотр без отправки

Из корня репозитория:

```sh
NEXT_PUBLIC_SERVER_URL=https://learn.mentorcareer.ru pnpm exec tsx scripts/preview-emails.ts
```

Команда создаёт `index.html`, HTML- и текстовые примеры всех писем (включая рассылку) в
игнорируемом `.codex/state/email-preview/`. Можно передать другую папку первым
аргументом. Данные примеров вымышленные, reset-token не действуют, писем команда
не отправляет. HTML можно открыть локально; для браузерного инструмента:

```sh
python3 -m http.server 3328 --bind 127.0.0.1 --directory .codex/state/email-preview
```

## Проверки

```sh
pnpm exec vitest run tests/unit/emailTemplates.test.ts tests/unit/emailTransport.test.ts tests/unit/emailTextAlternative.test.ts tests/unit/sendNotification.test.ts
```

Помимо содержания и ссылок проверяется настоящий MIME от Nodemailer без SMTP:
HTML-only восстановление становится multipart/alternative, содержит рабочую
ссылку в text/plain, а одновременные письма не смешивают имена и токены.
Общие проверки проекта: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`.
Браузерный HTML-предпросмотр не заменяет проверку доставленного письма в
Gmail, Яндекс Почте, Mail.ru и Outlook после выката.
