## Найденное и исправленное

1. Выбор 1,5× сбрасывался после перезагрузки: загрузка источника возвращала
   playbackRate к defaultPlaybackRate=1. Обе скорости теперь согласованы;
   повторное назначение уже установленного src исключено. Добавлены три
   регрессионных теста. Настоящий Chromium подтвердил 1,5× до/после reload.
2. Мобильное оглавление лендинга показывало предыдущий раздел после #trainer:
   геометрия менялась после загрузки шрифтов/включения шагов, а зона активации
   не учитывала scroll-padding. Начальный переход выравнивается после шрифтов,
   без перехвата пользовательского ввода; порог учитывает CSS. В Chromium
   целевой раздел остаётся около 144 px, подпись правильная.
3. Два FAIL были ошибками проверки: публичная страница намеренно не показывает
   неопубликованный урок даже администратору; «анонимный» Browser.newContext
   унаследовал сессию ученика. Теперь для него задано пустое storageState,
   а private CRUD/миниатюры и просмотр опубликованного кода/картинок/PDF разделены.
   Запросы существующего ученика для записи данных не использовались.
