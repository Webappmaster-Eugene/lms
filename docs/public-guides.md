# Публичные гайды

В CMS у гайда есть два независимых флага:

- **Опубликован** — материал готов к чтению.
- **Публичный гайд** — опубликованный материал доступен без входа и индексируется.

Для открытого материала включите оба. Включение только публичности не раскрывает
черновик. У прежних гайдов публичность выключена по умолчанию. Публичный материал
доступен всем, включая учеников с индивидуальным запретом: его можно прочитать
без аккаунта. У закрытых гайдов продолжают действовать назначения и запреты.

Открытая статья сохраняет адрес `/guides/<slug>`. Гостю доступны публичный каталог,
текст, оглавление, кнопка «Поделиться», вложения из медиатеки и скачивание Markdown.
Закладки и отзывы доступны после входа. При публикации публичными становятся
также файлы, на которые гайд ссылается в `/api/media/file/…`; проверьте их перед
включением флага, особенно если они используются в закрытых уроках.

SEO: индексируемые публичные статьи получают canonical, собственные Open Graph
и Twitter-метаданные, разметку Article и включаются в `/sitemap.xml`. Robots.txt
ссылается на sitemap. Закрытые материалы и черновики не включаются в sitemap,
гость получает 404 без текста и названия. Остальная LMS остаётся `noindex`.
Скачиваемый Markdown помечен `noindex`, чтобы основным поисковым результатом
оставалась HTML-статья. Индексация поисковиками происходит после их обхода.

При снятии публичности или публикации гостевой доступ и запись в sitemap
отзываются при следующем запросе; персональные назначения не меняются.
Ранее скачанные копии и сохранённые поисковиками сведения этим не удаляются.

В Markdown-шапке доступны `published: true` и `public: true`. Отсутствие `public`
при обновлении сохраняет прежнее значение, `public: false` явно закрывает гайд.
Публикация из файла: `pnpm guide:publish docs/guides/harness-maintenance.md`.
Для изменения только видимости через REST передавайте только `{ isPublic: true }`.

Миграция `20261025_162718_guides_public` добавляет булевы поля с default false в
`guides` и `_guides_v`, не меняя существующие материалы и их назначения.

Проверки: unit для политики и SEO, компонентные тесты отправки ссылки,
`tests/integration/guideAccess.test.ts` для REST и вложений,
`tests/integration/cms/migrations.test.ts` для старых данных и схемы,
`tests/e2e/specs/public-guides.spec.ts` для флага в CMS, гостевого HTML, SEO,
sitemap, скачивания и отзыва публичности.
