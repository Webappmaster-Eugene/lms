# Кеш учебного каталога

`src/server/learning-catalog.ts` загружает через Payload только выбранные поля,
с `depth: 0` и постраничной выборкой. Кешируются общие метаданные связей/публикации
и карточки карты: курсы, темы, линии. Содержимое уроков, видео, файлы, пользователи,
назначения, авторизация и прогресс в кеш не входят. После получения снимка
страница применяет свежую политику доступа, скрывает данные неназначенных курсов
и защищает ссылки в текстах. Назначения и срок их действия проверяются на каждом
запросе пользователя.

Перед чтением кеша PostgreSQL вычисляет ревизию `id + xmin` строк каталога.
Для карточек учитываются также связи prerequisites и дочерние bullets. Это
обнаруживает insert, update и delete, включая SQL update без изменения `updatedAt`.
Ревизия включена в неизменяемый ключ; после загрузки проверяется повторно.
При изменении во время загрузки снимок возвращается текущему запросу, но не
сохраняется в общий кеш. Чтение внутри транзакции всегда обходит оба уровня
кеша и использует ту же транзакцию Payload; незакоммиченные изменения не
публикуются. Ошибка авторитетной проверки БД не заменяется старым снимком.

Первый уровень — локальная память процесса, второй — Redis для нескольких
процессов/реплик. TTL обоих уровней — 5 минут; локально максимум 128 записей /
16 MiB, одна запись максимум 4 MiB. Одновременные cache miss одного ключа
объединяются. Redis connect/get/set имеют ограничение 150 мс на операцию;
offline queue и автоматическое переподключение выключены. После отказа 30 секунд
используется локальный кеш и Payload. Предупреждения не содержат URL или ошибок
клиента, которые могут раскрыть credentials. Повреждённый JSON или DTO из Redis
игнорируется и заменяется актуальной выборкой.

Docker Compose содержит `lms-mentor-redis` (`redis:7.4-alpine`), доступный только
приложению в отдельной `internal` сети `lms-cache`. Порт 6379 не публикуется.
Максимум Redis — 96 MiB, политика `allkeys-lru`, лимит контейнера — 128 MiB.
Persistence выключен: это восстанавливаемый кеш, потеря записей не влияет на БД.
Не публиковать Redis через Traefik или общий `dokploy-network`.

Если `REDIS_URL` отсутствует, Compose задаёт `redis://lms-mentor-redis:6379`.
Явное пустое значение отключает Redis; приложение продолжает использовать
локальный кеш. В `.env.example` URL пустой для локальной разработки. Для внешнего
Redis задаётся server-only `REDIS_URL` (при необходимости `rediss://` и auth);
не копировать URL с паролем в логи или документацию. Для включения на существующем
проде нужен согласованный выкат Compose и соответствующее значение в Dokploy UI.
Эти изменения сами по себе не меняют работающий прод.

Проверки:

```sh
pnpm test:unit tests/unit/contentCache.test.ts
pnpm test:integration tests/integration/cms/contentCache.test.ts
# Только против одноразового Redis, не production:
LMS_TEST_REDIS_URL=redis://127.0.0.1:56579 pnpm test:unit tests/unit/contentCacheRedis.test.ts
```

Проверки PostgreSQL покрывают актуальность после SQL update с прежним updatedAt,
изменения дочерних bullets и изоляцию rollback. Проверки настоящего Redis — общий
снимок между экземплярами модуля, TTL, повреждённый JSON и отказ подключения.
Unit-проверки — single-flight, изменение объекта потребителем, нестабильный
снимок, зависший Redis, повтор после ошибки loader и ограничения размера.
