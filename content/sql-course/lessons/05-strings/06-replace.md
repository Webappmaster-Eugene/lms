Кроме вырезания, строки можно менять: заменять фрагмент, удалять символы, повторять и переворачивать. Функции этого урока возвращают новое значение. Сама таблица при этом не меняется: чтобы записать результат в базу, нужен UPDATE.

## replace

Функция replace(строка, что, на что) заменяет все вхождения подстроки:

```sql run=shop
SELECT title, replace(title, 'Смартфон', 'Телефон') AS renamed
FROM products
WHERE category_id = 2;
```

Заменяются все вхождения, а не только первое. Регистр учитывается: слово «смартфона» со строчной «с» не совпадёт с «Смартфон». Если подстроки в значении нет, оно возвращается без изменений, а не пустым. Третий аргумент можно сделать пустой строкой, и тогда подстрока просто удаляется:

```sql run=empty
SELECT replace('+7 (916) 123-45-67', ' ', '') AS no_spaces,
       replace(replace('+7 (916) 123-45-67', '(', ''), ')', '') AS no_brackets;
```

Если нужно убрать много разных символов, вложенные replace быстро становятся громоздкими. Есть два более удобных способа: translate и регулярное выражение.

## translate

translate(строка, откуда, куда) заменяет символы по номерам: первый символ набора «откуда» на первый символ набора «куда», второй на второй и так далее. Если в наборе «куда» символов меньше, лишние символы из «откуда» удаляются:

```sql run=empty
SELECT translate('+7 (916) 123-45-67', '+()- ', '') AS digits,
       translate('abc', 'ab', 'xy') AS mapped;
```

Эта функция не ищет подстроку, она работает с отдельными знаками. Так удобно, например, убирать знаки пунктуации или приводить буквы к единому виду. Для замены целых слов нужен replace.

## Подсчёт вхождений и слов

Из длины и replace получается подсчёт, сколько раз в строке встречается символ. Удалите символ и сравните длину до и после. Функция lower здесь нужна, чтобы заглавная «О» тоже считалась:

```sql run=library
SELECT title,
       char_length(title) - char_length(replace(lower(title), 'о', '')) AS o_count
FROM books
WHERE id <= 4;
```

Тот же приём считает слова при условии, что они разделены одним пробелом: слов на одно больше, чем пробелов.

```sql run=library
SELECT title,
       char_length(title) - char_length(replace(title, ' ', '')) + 1 AS words
FROM books
WHERE id <= 4;
```

Если подстрока длиннее одного символа, длину разницы нужно разделить на длину подстроки. Двойные пробелы и пробелы по краям ломают подсчёт; для таких данных используйте regexp_count, о нём в следующем уроке.

## overlay

Функция overlay заменяет часть строки по позиции. Синтаксис: overlay(строка PLACING замена FROM позиция FOR длина). Это удобно для маскирования:

```sql run=empty
SELECT overlay('4276123456789012' PLACING '********' FROM 5 FOR 8) AS masked_card;
```

Тот же результат даёт склейка left || '********' || right, но overlay короче, когда позиции известны. Если FOR опущен, заменяется столько символов, сколько в строке замены.

Для адресов почты маску собирают из частей. Начало берётся через left, хвост от знака @ через substring:

```sql run=shop
SELECT email,
       left(email, 2) || '***' || substring(email FROM strpos(email, '@')) AS masked
FROM customers
WHERE email IS NOT NULL;
```

## repeat

repeat(строка, n) повторяет строку n раз. При n равном нулю или отрицательном получится пустая строка. Функция полезна для простейшей текстовой диаграммы:

```sql run=company
SELECT full_name, repeat('*', floor(salary / 50000)::integer) AS bar
FROM employees
WHERE department_id = 1
ORDER BY id;
```

Число повторов должно быть целым, поэтому дробное деление приводят к integer. floor отбрасывает дробную часть, а приведение numeric к integer без floor округлило бы число, и столбик получился бы длиннее.

## reverse

reverse(строка) переворачивает порядок символов. Прямого применения немного, но с её помощью решаются две типичные задачи. Первая - проверить, что строка читается одинаково в обе стороны:

```sql run=empty
SELECT word, word = reverse(word) AS is_palindrome
FROM (VALUES ('шалаш'), ('столб'), ('level')) AS t(word);
```

Вторая - найти позицию последнего вхождения. strpos ищет первое, но если развернуть строку, последний пробел окажется первым:

```sql run=empty
WITH t AS (SELECT 'Менеджер по продажам' AS s)
SELECT s,
       char_length(s) - strpos(reverse(s), ' ') + 1 AS last_space,
       reverse(left(reverse(s), strpos(reverse(s), ' ') - 1)) AS last_word
FROM t;
```

Для последнего слова проще split_part(s, ' ', -1), но принцип с разворотом работает с любым разделителем и в любой версии PostgreSQL.

## Что где использовать

Для подмены слова - replace. Для чистки набора знаков - translate. Для замены по позиции - overlay или склейка из left и right. Для повтора - repeat. Всё, что зависит от шаблона, а не от точных символов, решается регулярными выражениями в следующем уроке.
