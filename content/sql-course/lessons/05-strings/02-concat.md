Чтобы собрать из нескольких значений одну строку, в PostgreSQL используют оператор || (две вертикальные черты). Он соединяет текст слева и справа:

```sql run=company
SELECT full_name || ' - ' || position AS label
FROM employees
WHERE department_id = 3;
```

В MySQL две вертикальные черты по умолчанию означают логическое ИЛИ, а склейку делает функция CONCAT. В PostgreSQL оператор || и есть склейка, и именно его принято использовать. Функция concat тоже есть, но у неё иное поведение с пустыми значениями, как видно ниже.

## Склейка с числами

Если одна сторона - текст, а другая число или дата, PostgreSQL приводит вторую к тексту сам:

```sql run=library
SELECT title || ' (' || published_year || ')' AS caption
FROM books
WHERE id <= 3;
```

Для цен с копейками число склеится вместе с нулями после запятой. Чтобы убрать их, приведите значение к целому или отформатируйте через round и приведение типа:

```sql run=shop
SELECT title || ': ' || price AS raw, title || ': ' || price::integer AS rounded
FROM products
WHERE id IN (1, 5);
```

Если слева и справа стоят числа, оператор || не подходит: 1 || 2 без приведения вызовет ошибку, так как PostgreSQL не знает, что вы хотите склейку. Запишите одно из чисел как текст: 1::text || 2.

## NULL при склейке

Оператор || с NULL даёт NULL. Достаточно одного пустого значения, чтобы вся строка пропала:

```sql run=shop
SELECT full_name, city, full_name || ' (' || city || ')' AS label
FROM customers;
```

У покупателей без города подпись пустая. Исправить можно запасным значением через COALESCE, функцию, которая возвращает первый аргумент, не равный NULL:

```sql run=shop
SELECT full_name || ' (' || COALESCE(city, 'город не указан') || ')' AS label
FROM customers;
```

### concat и concat_ws

Функция concat принимает любое число аргументов и пропускает NULL, как будто там пустая строка. Склеивать в ней можно значения любых типов без приведения:

```sql run=shop
SELECT concat(full_name, ' (', city, ')') AS label
FROM customers;
```

Получилась подпись «Лев Комаров ()» с пустыми скобками: вместо NULL concat видит пустой текст, но остальные куски склеивает как обычно. Для списка значений через разделитель удобнее concat_ws, где первый аргумент - разделитель. Пустые значения она пропускает вместе с их разделителями:

```sql run=shop
SELECT concat_ws(', ', full_name, city, email) AS card
FROM customers;
```

У Олега Савина нет почты, у Льва Комарова нет города, но лишних запятых в строках нет. В MySQL у функции тоже такое поведение, и там это одна из причин пользоваться ею вместо CONCAT. Если разделитель сам равен NULL, concat_ws вернёт NULL.

Выбор между вариантами такой. Для фиксированного шаблона с обязательными частями подходит ||. Если часть может отсутствовать и должна исчезнуть вместе с разделителем, используйте concat_ws. Если нужно подставить запасное слово, используйте COALESCE внутри ||.

## Функции внутри склейки

Частью склейки может быть результат любой функции, которая возвращает текст. Повтор строки (repeat) и разворот (reverse) разобраны в уроке о замене, а здесь пример с upper и lower:

```sql run=empty
SELECT upper('sql') || '-' || lower('COURSE') AS code;
```

## Склейка значений многих строк

Все способы выше соединяют столбцы одной строки. Когда нужно собрать в одну строку значения из разных строк таблицы, например имена всех сотрудников отдела через запятую, используют агрегатную функцию string_agg. В MySQL ей соответствует GROUP_CONCAT. Агрегатные функции и группировка разобраны в разделе о группировке, а здесь только короткий пример, чтобы запомнить имя:

```sql run=company
SELECT string_agg(full_name, ', ' ORDER BY id) AS team
FROM employees
WHERE department_id = 1;
```

Функция возвращает одну строку на весь набор или на каждую группу. Порядок элементов внутри задаётся ORDER BY в скобках вызова; без него порядок не определён.
