Данные, которые вводят люди или импортируют из файлов, редко бывают чистыми: в начале и конце значений остаются пробелы, а вместе с ними знаки препинания, звёздочки и переводы строк. Такие значения выглядят одинаково, но сравниваются как разные: 'Казань' и 'Казань ' не равны. Функции этого урока наводят порядок.

## trim, ltrim и rtrim

Функция trim убирает пробелы с обоих краёв строки, ltrim только слева, rtrim только справа:

```sql run=empty
SELECT
  '[' || trim('  Анна Белова ') || ']' AS both_sides,
  '[' || ltrim('  Анна Белова ') || ']' AS left_side,
  '[' || rtrim('  Анна Белова ') || ']' AS right_side;
```

Квадратные скобки добавлены, чтобы пробелы было видно в результате. Внутренние пробелы trim не трогает: двойной пробел в середине строки останется как есть. Для них нужна замена, она разобрана в уроках о replace и регулярных выражениях.

Типичное применение - очистка перед сравнением или группировкой. Вместе с initcap получаются аккуратные названия:

```sql run=empty
WITH raw(city) AS (VALUES ('  москва'), ('КАЗАНЬ '), (NULL), (' санкт-петербург'))
SELECT city, initcap(trim(city)) AS clean
FROM raw;
```

Пустое значение остаётся пустым: функции строк не превращают NULL в строку.

### Символы, отличные от пробела

Чтобы убрать не пробелы, а другие символы, указывают набор. Полная запись trim принимает сторону (leading, trailing или both), набор символов и строку:

```sql run=empty
SELECT
  trim(both '*' FROM '***Скидки***') AS stars,
  trim(leading '0' FROM '000123') AS no_zeros,
  trim(trailing '!?' FROM 'Правда?!?!') AS no_marks;
```

Набор символов здесь - не слово, а список отдельных знаков. Из '!?' будут удалены любые восклицательные и вопросительные знаки с края, в каком бы порядке они ни стояли. Удаление идёт, пока с края не встретится символ не из набора. Те же возможности даёт btrim(строка, набор), ltrim(строка, набор) и rtrim(строка, набор):

```sql run=empty
SELECT btrim('xxабвxx', 'x') AS b, ltrim('0012', '0') AS l, rtrim('abc...', '.') AS r;
```

Если нужно убрать и пробелы, и звёздочки, пробел входит в набор: trim(both ' *' FROM title). Тогда сработает и для строки вроде ' * Акция * '.

## Другие невидимые символы

Табуляция, перенос строки и неразрывный пробел не считаются пробелом по умолчанию. trim без набора убирает только обычный пробел (код 32). Если в данных встречаются табы и переносы, добавьте их в набор через E-строку:

```sql run=empty
SELECT '[' || trim(both E' \t\n\r' FROM E'  \tтекст\n') || ']' AS cleaned;
```

Префикс E включает обработку управляющих последовательностей: \t это табуляция, \n перенос строки. Для более сложных случаев вроде неразрывных пробелов подойдёт регулярное выражение с классом \s.

## Дополнение до длины: lpad и rpad

Функции lpad и rpad делают обратную работу: дополняют строку до заданной длины слева или справа указанным символом. Если третий аргумент не указан, дополняется пробелами.

```sql run=company
SELECT id, 'EMP-' || lpad(id::text, 5, '0') AS code
FROM employees
WHERE id <= 3;
```

Число в lpad нужно привести к тексту: функция работает только со строками. Дополнять можно и многосимвольным шаблоном, он повторяется по кругу:

```sql run=empty
SELECT lpad('7', 6, 'ab') AS pad_left, rpad('7', 6, 'ab') AS pad_right;
```

Если исходная строка длиннее заданной длины, она не дополняется, а обрезается: lpad('abcdef', 3, '0') вернёт 'abc'. Поэтому длину берут с запасом, иначе длинные номера потеряют конец без предупреждения. Это самая частая ошибка с lpad.

### Выравнивание колонок

Для отчёта в текстовом виде lpad и rpad выравнивают столбцы: название по левому краю, число по правому.

```sql run=shop
SELECT rpad(title, 28, '.') || lpad(price::integer::text, 7, '.') AS line
FROM products
WHERE id <= 4
ORDER BY id;
```

В интерфейсах выравнивание делает вёрстка, а в SQL оно нужно для текстовых выгрузок и отладочных отчётов.

## SPACE и повтор пробелов

В MySQL функция SPACE(n) возвращает n пробелов. В PostgreSQL для этого используют repeat(' ', n). Функция repeat описана в уроке о замене. С её помощью легко сделать отступ по уровню вложенности:

```sql run=empty
SELECT repeat('  ', level) || name AS tree
FROM (VALUES (0, 'Компания'), (1, 'Разработка'), (2, 'Бэкенд')) AS t(level, name);
```

## Поиск грязных значений

Обрезка полезна и для проверки данных. Если значение отличается от своей обрезанной копии, в нём есть лишние пробелы:

```sql run=empty
WITH raw(id, city) AS (VALUES (1, 'Москва'), (2, ' Казань'), (3, 'Самара '), (4, NULL))
SELECT id, city
FROM raw
WHERE city <> trim(city);
```

Строка с NULL в результат не попала: сравнение с NULL не истинно ни для равенства, ни для неравенства, поэтому условие её отбрасывает. Такой запрос помогает найти строки, которые стоит почистить командой UPDATE (она разобрана в разделе об изменении данных).
