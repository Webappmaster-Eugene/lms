Иногда нужно не вырезать часть строки, а узнать, где в ней стоит нужное слово или символ. Для этого в PostgreSQL две функции с одинаковым результатом и разной записью.

## position и strpos

Функция position принимает подстроку и строку, соединённые словом IN. Функция strpos делает то же самое, но аргументы идут через запятую в обратном порядке: сначала строка, потом искомое:

```sql run=empty
SELECT
  position('@' IN 'olga@corp.example') AS pos1,
  strpos('olga@corp.example', '@') AS pos2;
```

Оба вызова возвращают номер первого символа найденной подстроки, считая с единицы. Если подстроки нет, результат 0. Это не ошибка и не NULL, поэтому проверка на отсутствие выглядит как strpos(...) = 0, а на наличие - strpos(...) > 0.

В MySQL похожие функции называются LOCATE(подстрока, строка) и INSTR(строка, подстрока). У LOCATE есть третий необязательный аргумент - позиция, с которой начать поиск. В PostgreSQL его нет, но тот же результат даёт поиск в срезе строки со сдвигом результата.

Поиск различает регистр. Чтобы найти слово в любом регистре, приведите строку к нижнему: strpos(lower(title), 'ноутбук'). Это удобный способ проверить, содержится ли слово в названии:

```sql run=shop
SELECT title, strpos(lower(title), 'ноутбук') AS pos
FROM products
WHERE strpos(lower(title), 'ноутбук') > 0
ORDER BY id;
```

Позиция показывает, где слово стоит: у «Ноутбук Air 13» это 1, у «Подставка для ноутбука» 15. Условие pos > 1 отберёт названия, где слово стоит не в начале.

## Проверка начала строки

Для проверки начала удобна функция starts_with, которая возвращает true или false:

```sql run=library
SELECT title
FROM books
WHERE starts_with(title, 'С')
ORDER BY id;
```

Тот же результат даёт title LIKE 'С%' и left(title, 1) = 'С'. Вариантов несколько, различие в читаемости. Для конца строки функции ends_with в PostgreSQL нет: пишут right(title, 2) = 'ру' или LIKE '%ру'.

Оператор LIKE подходит и для проверки «содержит», но он не говорит, в каком месте найдено совпадение. Если место нужно, берите strpos. Если нужно просто знать, есть ли подстрока, можно писать и strpos(...) > 0, и LIKE '%...%'.

## Позиция плюс вырезка

Позиция полезна в паре с substring и left. Чтобы вырезать часть между известными границами, сначала находят позицию границы, потом вырезают. Логин из почты - это всё до символа @:

```sql run=company
SELECT
  email,
  left(email, strpos(email, '@') - 1) AS login,
  substring(email FROM strpos(email, '@') + 1) AS domain
FROM employees
WHERE email IS NOT NULL AND id <= 3;
```

Для такого случая split_part короче и надёжнее. Но позиция выручает там, где разделителей несколько и резать нужно по первому найденному из них, или когда сама позиция нужна для расчёта.

### Первое слово без split_part

Простое решение для первого слова - split_part(x, ' ', 1). Через позицию это сложнее, потому что если пробела нет, strpos возвращает 0, а left с длиной -1 отрежет последний символ. Приём: дописать пробел в конец перед поиском, чтобы strpos всегда что-то находил.

```sql run=company
SELECT
  position AS full_position,
  left(position, strpos(position || ' ', ' ') - 1) AS first_word
FROM employees
WHERE id IN (1, 12);
```

У «Руководитель разработки» первое слово «Руководитель», а у «Стажёр» приписанный пробел оказывается сразу за словом, и результат совпадает со всей строкой.

## Номер повторного вхождения

Функция strpos всегда находит первое вхождение. Чтобы найти второе, ищут в остатке строки и прибавляют сдвиг. Например, позиция второго пробела в «Борис Громов младший»:

```sql run=empty
WITH t AS (SELECT 'Борис Громов младший' AS s)
SELECT s,
       strpos(s, ' ') AS first_space,
       strpos(s, ' ') + strpos(substring(s FROM strpos(s, ' ') + 1), ' ') AS second_space
FROM t;
```

Для частых случаев такой код лучше заменить split_part или регулярным выражением. Но принцип полезно знать: функции поиска легко комбинируются со срезами.

## Оператор ^@

Проверку начала строки умеет и оператор ^@: 'LT-0042' ^@ 'LT' даёт true, это то же самое, что starts_with. Для поиска подстроки в любом месте есть LIKE и ILIKE, они разобраны в разделе об условиях. Для начала хватает strpos, position и starts_with.
