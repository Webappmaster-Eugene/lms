Часто нужна не вся строка, а её кусок: первые буквы, домен из адреса, код из артикула. В PostgreSQL для этого несколько функций, и выбор между ними зависит от того, как заданы границы: по позициям или по разделителю.

## substring по позиции

Основная функция - substring. Ей передают строку, позицию первого нужного символа и, по желанию, длину:

```sql run=empty
SELECT
  substring('LT-0042-RU' FROM 4 FOR 4) AS number,
  substring('LT-0042-RU' FROM 4) AS tail,
  substring('LT-0042-RU', 1, 2) AS head;
```

Позиции считаются с единицы. Запись FROM ... FOR ... соответствует стандарту SQL; запись через запятую substring(строка, начало, длина) делает то же самое. Если длина не указана, берётся всё до конца строки. Если начало выходит за конец, результат пустая строка. Те же возможности даёт функция substr, а MySQL-функция MID в PostgreSQL называется substring.

Начало может быть меньше единицы, тогда нужные позиции сдвигаются, а часть длины уходит «в пустоту»:

```sql run=empty
SELECT substring('привет' FROM 0 FOR 3) AS shifted, substring('привет' FROM -1 FOR 4) AS shifted_more;
```

Первый запрос охватывает позиции 0, 1 и 2, но существуют только две из них, поэтому он вернёт «пр». Второй охватывает позиции от -1 до 2 и тоже вернёт «пр». Такая арифметика редко нужна, но объясняет странный результат, если границы посчитаны неточно.

## left и right

Начало и конец строки берут функции left и right:

```sql run=library
SELECT title, left(title, 5) AS start, right(title, 4) AS finish
FROM books
WHERE id <= 4;
```

Если передать отрицательное число, функция отрежет столько символов с противоположного края: left('abcdef', -2) вернёт 'abcd', а right('abcdef', -2) вернёт 'cdef'. Это удобный способ «убрать последние несколько символов»:

```sql run=empty
SELECT left('report.csv', -4) AS name, right('report.csv', 3) AS ext;
```

## Сокращение длинного текста

Типичная задача для вывода в таблице интерфейса: показать первые N символов и многоточие, но только там, где текст длиннее:

```sql run=shop
SELECT
  title,
  CASE WHEN char_length(title) > 12 THEN left(title, 12) || '...' ELSE title END AS preview
FROM products
ORDER BY id
LIMIT 6;
```

Если дописывать многоточие всем без разбора, короткие названия получат его зря.

## split_part

Когда фрагмент ограничен не позицией, а символом-разделителем, удобнее split_part. Функция делит строку по разделителю и возвращает часть с нужным номером. В MySQL это делает SUBSTRING_INDEX, но в PostgreSQL логика другая: возвращается ровно одна часть, а не всё до n-го разделителя.

```sql run=company
SELECT
  email,
  split_part(email, '@', 1) AS login,
  split_part(email, '@', 2) AS domain
FROM employees
WHERE email IS NOT NULL AND id <= 3;
```

Номер части считается с единицы. Если частей меньше, чем запрошено, получится пустая строка, а не ошибка. Отрицательный номер отсчитывает части с конца (начиная с PostgreSQL 14), поэтому последнее слово берётся так:

```sql run=company
SELECT position, split_part(position, ' ', -1) AS last_word
FROM employees
WHERE id IN (1, 8, 12);
```

Несколько split_part подряд позволяют разобрать строку на поля. Для имени из двух слов получаются имя и фамилия, из них собирается сокращённая запись:

```sql run=company
SELECT left(split_part(full_name, ' ', 1), 1) || '. ' || split_part(full_name, ' ', 2) AS short_name
FROM employees
WHERE id <= 4;
```

## Выбор функции

Если границы известны заранее и всегда одинаковы, например код страны в последних двух буквах артикула, подходят left, right и substring. Если фрагмент определяется соседним символом, например домен после @, подходит split_part. Если же нужна часть, которую описывает шаблон, например число перед знаком процента, используется substring с регулярным выражением, о нём в уроке о регулярных функциях.

Все функции этого урока возвращают NULL, если на входе NULL. Если нужно получить пустую строку вместо NULL, оберните результат в COALESCE.
