Кроме операторов в PostgreSQL есть набор встроенных функций для чисел. Они вызываются в любом месте, где допустимо выражение: в списке столбцов, в WHERE и в ORDER BY. Все функции этого урока работают построчно: берут значения из одной строки и возвращают одно значение для неё.

## ABS и SIGN

`ABS(x)` возвращает модуль числа, `SIGN(x)` - только его знак: -1, 0 или 1. Вместе они хорошо описывают отклонения: насколько и в какую сторону.

```sql run=empty
SELECT
  delta,
  ABS(delta) AS distance,
  SIGN(delta) AS direction
FROM (VALUES (-15), (0), (8)) AS t(delta);
```

Отклонение факта от плана считают так: `actual - planned` показывает направление, а `ABS(actual - planned)` - размер без знака. Если нужно отобрать все расхождения больше тысячи в любую сторону, пишут `WHERE ABS(actual - planned) > 1000`, а не два условия.

## MOD и оператор %

`MOD(a, b)` возвращает остаток от деления, и это то же самое, что `a % b`. Остаток от деления на 2 говорит о чётности, на 7 - о положении в неделе, на 60 - о секундах, которые не вошли в минуты.

```sql run=empty
SELECT
  seconds,
  seconds / 60 AS minutes,
  MOD(seconds, 60) AS seconds_left
FROM (VALUES (45), (187), (3725)) AS t(seconds);
```

Целочисленное деление на 60 и остаток вместе разбирают секунды на минуты и секунды. Для отрицательных чисел остаток берёт знак делимого: `MOD(-7, 3)` равно -1, а не 2. Если нужен всегда неотрицательный остаток, помогает `MOD(MOD(x, n) + n, n)`.

## POWER и SQRT

`POWER(x, y)` возводит число в степень, `SQRT(x)` извлекает квадратный корень. Для целых аргументов обе функции возвращают double precision, а для numeric - numeric. В MySQL `POW` и `POWER` - синонимы, в PostgreSQL `POW` тоже существует, но стандартное имя `POWER`. Есть и оператор `^`, например `2 ^ 10`.

```sql run=empty
SELECT
  POWER(2, 10) AS two_pow_ten,
  POWER(3::numeric, 3) AS cube,
  SQRT(144) AS root,
  ROUND(SQRT(2)::numeric, 4) AS root_of_two;
```

Результат `SQRT` имеет тип double precision, а `ROUND(x, n)` с таким типом не работает, поэтому перед округлением нужно привести значение к numeric. Об этом - в уроке про округление.

Корень из отрицательного числа - ошибка: PostgreSQL не вычисляет комплексные числа.

```sql run=empty error
SELECT SQRT(-4);
```

## GREATEST и LEAST

`GREATEST(a, b, ...)` возвращает наибольшее из своих аргументов, `LEAST(a, b, ...)` - наименьшее. Количество аргументов любое, типы должны быть совместимы.

```sql run=empty
SELECT
  GREATEST(3, 17, 9) AS biggest,
  LEAST(3, 17, 9) AS smallest,
  GREATEST(120, LEAST(50, 400)) AS clamped_low,
  LEAST(2000, GREATEST(5000, 100)) AS clamped_high;
```

Эти функции позволяют ограничить значение с двух сторон: нижняя граница задаётся через `GREATEST`, верхняя через `LEAST`. Пример: комиссия 2 процента, но не меньше 50 рублей и не больше 500:

```sql run=shop
SELECT title, price, LEAST(GREATEST(price * 0.02, 50), 500) AS fee
FROM products
ORDER BY id
LIMIT 6;
```

Не путайте их с агрегатами `MIN` и `MAX`. `GREATEST` сравнивает значения в пределах одной строки, а `MAX` сворачивает весь столбец по строкам в одно значение. Агрегаты разбираются в разделе о группировке.

Ещё одно отличие от MySQL: в PostgreSQL `GREATEST` и `LEAST` пропускают NULL и возвращают NULL, только если все аргументы NULL. В MySQL один NULL делает NULL весь результат.

```sql run=empty
SELECT GREATEST(5, NULL, 3) AS skips_null, LEAST(NULL, NULL) AS all_null;
```

## RANDOM

`RANDOM()` возвращает случайное число от 0 (включительно) до 1 (не включая). Это double precision, которое при каждом вызове разное. В MySQL функция называется `RAND`. Типичные применения: выбрать случайную строку или перемешать выдачу.

```sql
SELECT title FROM products ORDER BY RANDOM() LIMIT 1;
```

Этот запрос в уроке не выполняется: результат менялся бы при каждом запуске, а примеры должны быть воспроизводимыми. Запустите его в своей базе, и каждый раз будет приходить другой товар. Случайное целое число от 1 до 6 получают так: `FLOOR(RANDOM() * 6) + 1`. Для больших таблиц `ORDER BY RANDOM()` медленный, потому что сортирует все строки, но для небольших выборок подходит.

В задачах тренажёра функция `RANDOM` не используется: результат нельзя сравнить с эталоном, ведь ответ каждый раз другой.

## Где пригодятся функции

В повседневной работе ABS и SIGN встречаются при анализе расхождений, MOD - при выборке каждой n-й строки и при разборе единиц времени, POWER - в финансовых формулах сложного процента, SQRT - в расчётах расстояний, а GREATEST и LEAST - в ограничении значений минимумом и максимумом. Большинство остальных сложных вычислений строится из этих блоков и операторов.
