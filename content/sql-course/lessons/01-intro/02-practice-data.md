Все примеры и задачи курса используют три небольшие учебные базы. Их удобно держать перед глазами: в задачах будут нужны и названия столбцов, и сами значения.

## Компания

Набор `company` описывает компанию с отделами и сотрудниками. Таблица отделов уже знакома по прошлому уроку:

```tables company departments
```

В таблице сотрудников есть имя, отдел, должность, зарплата, даты приёма на работу и рождения, почта и номер руководителя. Столбец `manager_id` ссылается на другую строку этой же таблицы: у Игоря Петрова руководитель с номером 1, то есть Ольга Смирнова. У стажёра Виктора Зайцева нет ни отдела, ни руководителя, а у некоторых сотрудников не указана почта.

```tables company employees
```

## Интернет-магазин

Набор `shop` устроен сложнее. В нём категории товаров, товары, покупатели, заказы и состав заказов. Один заказ может содержать несколько товаров, поэтому для состава заказа заведена отдельная таблица `order_items`: в каждой её строке номер заказа, номер товара, количество и цена, по которой товар продан.

```tables shop
```

## Библиотека

Набор `library` небольшой: авторы и их книги. У одной книги автор неизвестен, а у Анны Ахматовой в базе нет ни одной книги. Такие пробелы пригодятся, когда дойдём до соединения таблиц.

## Как решать задачи

Задача открывается в тренажёре: слева условие и таблицы, справа редактор. Напишите запрос и нажмите «Запустить». Тренажёр поднимет чистую базу с данными из условия, выполнит ваш запрос и покажет результат рядом с ожидаемым. «Запустить» ничего не засчитывает, им можно пользоваться сколько угодно.

Когда результат совпадает, нажмите «Отправить». Сервер проверит решение ещё раз, теперь на открытых данных и на скрытом наборе. Скрытый набор устроен так же, как открытый, но строки в нём другие. Поэтому решение должно работать по смыслу, а не по конкретным значениям. Запрос `SELECT 'Анна Волкова'` выведет нужное имя на открытых данных, но на скрытых провалится.

Проверка сравнивает названия столбцов, их порядок и сами строки. Если в условии сказано назвать столбец `total`, столбец с другим именем не засчитается. Порядок строк проверяется, только когда этого требует условие. Пустое значение в таблицах записано как NULL. Если же значение - текст, который иначе не отличить от другого (с пробелом в начале или в конце, пустая строка, само слово NULL), оно показано в кавычках, как в SQL: `' Москва'`, `''`, `'NULL'`.

## Как повторить примеры у себя

Тренажёра достаточно, чтобы пройти курс. Он работает на PostgreSQL 18, и примеры курса рассчитаны на эту версию. Если хочется попробовать запросы в настоящей базе, проще всего запустить PostgreSQL той же версии в Docker и подключиться к нему клиентом psql:

```text
docker run --name sql-course -e POSTGRES_PASSWORD=secret -p 5432:5432 -d postgres:18
docker exec -it sql-course psql -U postgres
```

SQL для создания учебных таблиц с данными можно скопировать на вкладке «Тесты» любой задачи: там он показан в поле «Подготовка данных».
