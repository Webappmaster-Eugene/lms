Запрос на чтение начинается со слова SELECT. После него перечисляют столбцы, которые нужно получить, а после FROM указывают таблицу. Самый короткий запрос выбирает всё:

```sql run=company
SELECT * FROM departments;
```

Звёздочка означает все столбцы в том порядке, в каком они объявлены в таблице. Это удобно, когда нужно быстро посмотреть на данные. В коде приложения так обычно не пишут: если в таблицу добавят столбец, запрос начнёт возвращать лишнее, а программа, которая ждала четыре столбца, получит пять.

## Нужные столбцы

Чтобы получить только часть столбцов, перечислите их через запятую:

```sql run=company
SELECT full_name, position FROM employees;
```

Столбцы приходят в том порядке, в каком вы их написали, а не в том, в каком они лежат в таблице. Один и тот же столбец можно указать дважды, и он придёт дважды:

```sql run=library
SELECT title, published_year, title FROM books;
```

Если ошибиться в имени столбца, PostgreSQL не станет угадывать и вернёт ошибку с подсказкой:

```sql run=company error
SELECT full_name, salry FROM employees;
```

## Порядок строк

В запросах выше нет никакого указания, в каком порядке выводить строки. Сейчас они пришли по возрастанию `id`, но это совпадение. Без сортировки PostgreSQL отдаёт строки в том порядке, в каком ему удобно их читать, и после изменений в таблице этот порядок может поменяться. Когда порядок важен, его задают явно через ORDER BY. Этому посвящён урок о сортировке.

## Запрос в несколько строк

SQL не обращает внимания на переносы строк и лишние пробелы. Длинный запрос удобнее писать в несколько строк, по одной части на строку:

```sql run=shop
SELECT
  title,
  price,
  stock
FROM products;
```

Так проще читать запрос и искать ошибку: PostgreSQL сообщает номер строки, в которой споткнулся.
