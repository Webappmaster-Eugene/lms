# MentorCareer LMS — учебная платформа

Next.js 15 App Router + Payload CMS 3 на PostgreSQL, тренажёр задач с исполнением
пользовательского кода в песочнице, лендинг на Astro. Прод — один сервер, деплой
через Dokploy по пушу в `main`.

## Чего никогда не делать

- **Пушить в `main` без спроса.** Пуш = деплой на прод. Это решение человека.
- **Править `src/migrations/*` вручную.** Миграции только через
  `pnpm payload migrate:create`, и новая должна попасть в `src/migrations/index.ts`.
- **Удалять колонку тем же выкатом, что меняет код.** Миграции применяются на
  старте контейнера; схема изменений — expand-contract, в три шага.
- **Прокидывать переменные окружения в дочерний процесс песочницы.** Его пустое
  окружение — граница безопасности тренажёра, а не недосмотр.
- **Коммитить `.env`, `media/`, дампы БД.** Секреты только из `process.env`.
- **Считать, что БД доступна локально.** Postgres есть только на сервере;
  `pnpm build` требует `DATABASE_URL` и `PAYLOAD_SECRET`.
- **Менять прод без подтверждения пользователя.** Перевыкат стирает следы.
