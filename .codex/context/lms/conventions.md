# Соглашения кода

- TypeScript strict. `any`, non-null assertion и `console.log` запрещены линтером;
  список исключений в `eslint.config.mjs` расширять только с причиной в комментарии.
- React 19 и App Router: серверные компоненты по умолчанию, `'use client'` — только
  там, где действительно нужен браузер.
- Одинарные кавычки, без точек с запятой, 2 пробела.
- Импорты через `@/…` и `@payload-config`. Алиасы продублированы в
  `vitest.config.ts` — при правке `tsconfig.json` менять оба.
- Комментарии узкие и только «почему». «Что делает» видно из кода.
- Ошибки не проглатывать молча: лог и внятное сообщение пользователю.
- Выборки из Payload — постранично через `src/lib/paginate.ts`, а не до
  фиксированного лимита.
- Составные операции с побочными эффектами (баллы, сертификаты, уведомления)
  выполнять в общей транзакции.
- Права коллекции задавать явно: коллекция без `access` открыта наружу.
- Тексты для пользователя и писем — по-русски.
- Коммиты: `type(scope): суть по-русски`.
